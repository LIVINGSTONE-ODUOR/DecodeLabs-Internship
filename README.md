## Features

- **Modern dark tech UI** (neon green accents + gradients)
- **Fully responsive** layout (mobile/tablet/desktop)
- **Sticky navbar** with smooth scrolling
- **Scroll reveal animations** (IntersectionObserver)
- **Testimonials slider**
- **Animated stats counters**
- **AI Chat Assistant widget** (floating “Ask Stone AI” experience)
- **Contact form** with client-side validation and toast feedback
- **Performance-friendly** behavior (reduced-motion support, lazy assets already used in markup)

## Project Structure

- `index.html` — Main landing page (all sections)
- `styles.css` — Design system + UI styling
- `script.js` — Interactive behavior (navbar, animations, slider, forms, chat)
- `assets/` — Images and brand assets

## Local Setup / Run

This project is static—no backend required.

1. Open `index.html` in a browser.
   - Recommended: use a simple local server for best results with browser features.

## Editing / Customization

### Branding
- Update the text/logo in `index.html`.
- Update colors by editing CSS variables in `styles.css` under `:root`.

### Interactions
- Modify behavior in `script.js`:
  - Mobile menu
  - Smooth scrolling
  - Scroll reveal
  - Testimonials slider
  - Contact form submission UX
  - AI chat responses

## Notes

- The JavaScript was stabilized and deduplicated to ensure predictable runtime behavior.
- Quote/admin features are not implemented in this commit (website foundation + core interactions are in place).

You can deploy directly to any static hosting provider (GitHub Pages, Netlify, Vercel Static, etc.).
